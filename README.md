# Il nostro ricettario

App web (PWA) per il ricettario di famiglia: https://marcopigozzi99-prog.github.io/Ricettario/

318 ricette di cucina di tutti i giorni divise in 8 capitoli, con home "Stasera", piano settimanale di stagione, lista della spesa automatica, frigo e dispensa, "Sorprendimi", preferiti, ricette proprie, timer e modalità cucina. Funziona anche offline e si può aggiungere alla schermata Home del telefono. L'account e la "Famiglia" (facoltativi) permettono di condividere piano, spesa e preferiti tra più telefoni.

App gratuita e di famiglia: niente pubblicità, niente abbonamenti.
